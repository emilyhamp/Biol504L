These notes follow my code from transcript quantification (using Salmon) through differential gene expression and GO enrichment.

The analysis includes five freshly laid samples, five 36-hour normoxia samples, and five 36-hour hypoxia samples. The comparison extracted here is hypoxia versus normoxia at 36 hours.

3. Make the transcript-to-gene table

# Folder containing the GTF, metadata, and saved R results.
dir <- "/Users/emilyhamp/Desktop/Cmydas_DGE/"

# Read the turtle GTF annotation into a transcript database.

5. Define groups and create the DESeq2 dataset

# Use the Condition text in the metadata to assign experimental groups.
# In this specific metadata file, the remaining samples are freshly laid.
# For another dataset, check unmatched conditions rather than assuming this.
samples$group <- factor(
  ifelse(
    grepl("normoxia", samples$Condition, ignore.case = TRUE),
    "Normoxia",
    ifelse(
      grepl("hypoxia", samples$Condition, ignore.case = TRUE),
      "Hypoxia",
      "Freshly_laid"
    )
  ),
  levels = c("Normoxia", "Hypoxia", "Freshly_laid")
)

table(samples$group) # Expected from my metadata: 5 samples per group

# Build the dataset from gene-level Salmon imports and sample metadata.
# ~ group models differences among the three groups.
# Normoxia is the reference because it is the first factor level.
dds <- DESeqDataSetFromTximport(
  txi,
  colData = samples,
  design = ~ group
)

# Genes are rows; samples are columns; entries are count estimates.
View(counts(dds))

6. Explore sample relationships

7. Filter low counts and run differential expression

# Keep genes with at least 10 counts TOTAL across all samples.
# This does not require 10 counts in each individual sample.
good_rows <- rowSums(counts(dds)) >= 10
dds <- dds[good_rows,]

# Fit the DESeq2 model, accounting for normalization and count variation.
dds <- DESeq(dds)

resultsNames(dds) # Display the fitted model's coefficient names

# Extract Hypoxia relative to Normoxia at 36 hours.
# Positive log2 fold change = higher estimated expression in hypoxia.
# Negative log2 fold change = lower estimated expression in hypoxia.
res_hypoxia_normoxia <- results(
  dds,
  contrast = c("group", "Hypoxia", "Normoxia"),
  alpha = 0.05
)

summary(res_hypoxia_normoxia)

log2FoldChange reports the effect size. padj reports the multiple-testing-adjusted p-value. A log2 fold change of 1 corresponds to a twofold ratio.

8. Shrink fold changes with apeglm and make MA plots

# Shrink uncertain log2 fold-change estimates using apeglm.
res_hypoxia_normoxia_apeglm <- lfcShrink(
  dds,
  coef = "group_Hypoxia_vs_Normoxia",
  type = "apeglm",
  res = res_hypoxia_normoxia
)

summary(res_hypoxia_normoxia_apeglm)

# MA plots: mean normalized expression versus log2 fold change.
# Compare the original and shrunken estimates.
plotMA(res_hypoxia_normoxia, ylim = c(-2, 2))
plotMA(res_hypoxia_normoxia_apeglm, ylim = c(-2, 2))

# Save the apeglm results.
out_csv <- file.path(dir, "Hypoxia_vs_Normoxia.DEG.csv")
write.csv(as.data.frame(res_hypoxia_normoxia_apeglm), file = out_csv)

11. Label expression changes and make the volcano plot

# Convert ashr results to a data frame and preserve the gene IDs.
res_df <- as.data.frame(result_hypoxia_normoxia_ashr)
res_df <- tibble::rownames_to_column(res_df, var = "gene")

# Remove genes lacking an adjusted p-value from this plotting/enrichment table.
res_df <- res_df %>% filter(!is.na(padj))

# Label genes using BOTH an effect-size and a significance threshold.
# UP: more than twofold higher estimated expression in hypoxia.
# DOWN: less than half the estimated expression in hypoxia.
# NOT: does not meet both criteria; it does not prove no biological effect.
res_df <- res_df %>%
  mutate(diffexpressed = case_when(
    log2FoldChange > 1 & padj < 0.05 ~ "UP",
    log2FoldChange < -1 & padj < 0.05 ~ "DOWN",
    TRUE ~ "NOT"
  ))

table(res_df$diffexpressed) # Count genes assigned to each label

# Plot effect size against statistical evidence, with one point per gene.
ggplot(res_df, aes(
  x = log2FoldChange,
  y = -log10(padj),
  color = diffexpressed
)) +
  geom_point(alpha = 0.6, size = 1.5) +
  scale_color_manual(
    values = c("DOWN" = "blue", "NOT" = "grey", "UP" = "red")
  ) +
  geom_vline(xintercept = c(-1, 1), linetype = "dashed") +
  geom_hline(yintercept = -log10(0.05), linetype = "dashed") +
  theme_minimal() +
  labs(
    x = "log2 Fold Change (Hypoxia / Normoxia)",
    y = "-log10 Adjusted p-value",
    color = "Expression"
  )

13. Prepare gene sets and run GO enrichment

# Separate all selected DEGs, UP genes, and DOWN genes.
sig_degs <- res_df %>% filter(diffexpressed != "NOT")
only_up_degs <- res_df %>% filter(diffexpressed == "UP")
only_down_degs <- res_df %>% filter(diffexpressed == "DOWN")

# Extract the gene names rather than the entire result rows.
all_gene_names <- res_df$gene
sig_deg_names <- sig_degs$gene
sig_up_names <- only_up_degs$gene
sig_down_names <- only_down_degs$gene

clean_sig_deg_names <- sig_deg_names
clean_uni_names <- all_gene_names
clean_sig_up_names <- sig_up_names
clean_sig_down_names <- sig_down_names

# Combined UP and DOWN gene set: biological-process enrichment.
ego <- enrichGO(
  gene = clean_sig_deg_names,
  universe = clean_uni_names, # Background: genes in my processed res_df
  OrgDb = org_db,             # Turtle annotations
  keyType = "SYMBOL",         # Identifier type used by my result genes
  ont = "BP",                 # Biological process
  pAdjustMethod = "BH",       # Benjamini-Hochberg multiple-testing adjustment
  qvalueCutoff = 0.05,
  readable = TRUE
)

# UP genes: test all three GO categories for the faceted plot.
sig_up_ego <- enrichGO(
  gene = clean_sig_up_names,
  universe = clean_uni_names,
  OrgDb = org_db,
  keyType = "SYMBOL",
  ont = "ALL",                # BP, molecular function, cellular component
  pAdjustMethod = "BH",
  qvalueCutoff = 0.05,
  readable = TRUE
)

# DOWN genes: biological-process enrichment.
sig_down_ego <- enrichGO(
  gene = clean_sig_down_names,
  universe = clean_uni_names,
  OrgDb = org_db,
  keyType = "SYMBOL",
  ont = "BP",
  pAdjustMethod = "BH",
  qvalueCutoff = 0.05,
  readable = TRUE
)

GO enrichment tests whether annotated functions occur more often in a selected gene set than expected from the background.

What my GO enrichment analysis compared

My GO enrichment analysis compared the functions represented in my selected genes with the functions represented in the background genes from my analysis.

  • Selected genes: my UP genes, DOWN genes, or both combined. These genes had an adjusted p-value below 0.05 and an absolute log2 fold change greater than 1.
  • Background genes: all genes remaining in res_df, including UP, DOWN, and NOT genes. Genes without usable GO annotations could not contribute to the relevant enrichment comparison.

The turtle annotation database supplied information about which functions each gene is associated with. It was not a separate control expression dataset.

For example, if 10% of the annotated background genes were associated with oxygen transport, but 40% of my UP genes were associated with it, GO enrichment would test whether this function was unusually common among my UP genes.

DESeq2 compared expression between hypoxia and normoxia samples. GO enrichment then compared the functions represented in my selected gene sets with those represented in my background gene set.

Short methods summary

RNA-seq transcript abundances were quantified with Salmon on the HPC and imported into R with tximport using a transcript-to-gene mapping derived from the C. mydas rCheMyd1.pri.v2 GTF annotation. Fifteen samples were assigned to freshly laid, 36-hour normoxia, and 36-hour hypoxia groups, with five samples per group. Sample relationships were explored using rlog-transformed PCA and correlation heatmaps. Genes with fewer than 10 total counts across samples were removed, and DESeq2 was fitted with design = ~ group. Hypoxia was contrasted against normoxia. Both apeglm and ashr fold-change shrinkage were explored; downstream gene classification used ashr estimates, adjusted p-value < 0.05, and absolute log2 fold change > 1. GO overrepresentation analysis used clusterProfiler and the turtle AnnotationHub OrgDb record AH120704 with gene symbols and the analyzed, non-missing-padj gene set as the supplied background. Combined and DOWN gene sets were tested for biological-process enrichment, while the UP set was tested across all three GO categories. Benjamini-Hochberg adjustment and a q-value cutoff of 0.05 were specified.
